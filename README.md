# WOD Log

A personal CrossFit / gym tracker that runs as a home-screen web app.

- Strength / skill blocks: sets × weight × reps, with a barbell plate loader
- Conditioning blocks: For Time, AMRAP, EMOM, with per-exercise rep schemes (same, ladder, custom)
- History, exercise stats and PRs
- Works offline; data is stored on the device (export a backup from Settings)

Install on iPhone: open the site in Safari → Share → Add to Home Screen.
